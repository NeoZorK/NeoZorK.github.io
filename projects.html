PROJECT 01 · Trading systems

Working tool

This project is a high-performance Python application designed to replay historical and live trading data while calculating mid-prices with latency filtering. It provides a unified abstraction for processing large volumes of financial data, supporting dynamic switching between historical replay and live simulation via WebSocket. The system utilizes Redis Streams for a high-throughput message queue and includes a separate application for mid-price calculation that filters messages based on configurable latency thresholds. It features state persistence to resume processing from the last point and uses structured logging throughout. The codebase is built with Python 3.12+ and relies on libraries including asyncio-mqtt, numpy, pandas, pydantic, redis, and sentence-transformers. It is containerized using Docker and docker-compose. The project contains unit tests with 100% coverage and includes markdown documentation. It is currently a working-tool suitable for simulation and testing environments.
